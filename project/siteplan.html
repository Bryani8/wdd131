OCEANVERSE | Autonomous Marine Telemetry

Site Name

OCEANVERSE is a platform that allow us to visualize and analize the data from Autonompus Underwater Vehicles (AUV) and IoT nodes in the ocean.

Site Purpose

This platform is a dashboard that displays real-time operational metrics, navigation logs and telemetry for AUV's and IoT nodes during oceanographic deployments.

Scenarios

What is the current depth and battery volatge of the deployed vehicle?

How can I filter recent mission logs by alert severity or timestamp?
